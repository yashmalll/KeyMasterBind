# KeyMasterBind

Локальное Linux-приложение на Rust с русским веб-интерфейсом для 19-клавишной INSTANT USB Keyboard (`30fa:2350`). Без зависимостей Cargo, npm и облака. Интерфейс встроен в бинарник.

## Запуск

```sh
cargo build --release --offline
./target/release/keymasterbind
```

Открыть **http://127.0.0.1:8765**. Запускать из каталога проекта: `config.json` хранится в текущем рабочем каталоге. Сервер доступен только на loopback. Веб-сервер не нужно запускать от root.

Для реального перехвата нужны Linux evdev и `/dev/uinput`. Если прав нет, один раз настройте доступ (команды выполняются пользователем на хосте):

```sh
sudo groupadd -f keymasterbind
sudo usermod -aG keymasterbind "$USER"
sudo install -m 644 packaging/70-keymasterbind.rules /etc/udev/rules.d/70-keymasterbind.rules
sudo modprobe uinput
sudo udevadm control --reload-rules
sudo udevadm trigger --subsystem-match=misc
```

Переподключите клавиатуру, затем выйдите из пользовательского сеанса и войдите снова, чтобы применить группу. После перезагрузки загрузите `uinput` снова или настройте его загрузку через `/etc/modules-load.d/`. Группа имеет право генерировать системный ввод: добавляйте в неё только свой доверенный аккаунт.

## Настройка

1. Выберите основной интерфейс `INSTANT USB Keyboard` (не Mouse / Consumer Control) и включите перехват.
2. Выберите одну из 19 кнопок → «Определить по нажатию» → нажмите физическую клавишу.
3. Выберите действие: сочетание, макрос, отключение или обычная клавиша. Нажмите «Применить к кнопке» и «Сохранить».
4. Для макроса используйте строки `29,46 @ 100`: Ctrl+C, отпускание всех клавиш, затем пауза 100 мс. Коды — **Linux evdev**, не USB HID. Удержание сочетания повторяет последнюю клавишу; макрос запускается один раз на нажатие.
5. Создавайте профили, переключайте их и сохраняйте. Профили можно импортировать/экспортировать JSON-файлом.

Расположение 19 кнопок условное; исходные коды заданы как пример цифрового блока и уточняются определением по нажатию. Каждый профиль хранит собственную раскладку. Сохранённые изменения подхватываются на следующем нажатии; отпускание использует исходное назначение, чтобы не оставлять модификаторы зажатыми. Коды в интерфейсе отображаются при активном перехвате.

## Ограничения

- Переназначения работают, пока запущено приложение и включён перехват. При запуске он выключен.
- Перехватывается один выбранный event-интерфейс. Отдельные мультимедийные и мышиные интерфейсы не переназначаются. Если часть клавиш не определяется, остановите перехват и выберите другой клавиатурный интерфейс этого устройства.
- После отключения устройства или потери событий нужно включить перехват снова. Основная клавиатура не захватывается: разрешены только устройства `30fa:2350`.
- Макросы выполняются последовательно: до 64 шагов, до 2 секунд на паузу, до 5 секунд всех пауз. Остановка может ожидать окончания текущего макроса. Запуск программ и ввод произвольного текста пока не реализованы.
- Работа рассчитана на Linux с ABI ioctl asm-generic (проверена сборка x86_64). Другие ОС не поддерживаются.

## Встроенная память и прошивка

**Запись в устройство НЕ реализована.** Вкладка памяти показывает это явно; API прошивки и команд перевода в загрузчик нет. Произвольный файл не отправляется устройству.

Для реализации записи нужны подтверждённые модель платы/контроллера, родная утилита, формат конфигурации, протокол записи и восстановления. Один VID/PID не определяет совместимость. Сохранение назначений в EEPROM и замена исполняемой прошивки — разные операции; поддержку нужно определять для конкретной платы.

## Проверки

```sh
cargo test --offline
cargo clippy --offline -- -D warnings
node --check web/app.js
python3 tests/http_smoke.py
```

HTTP smoke-тест собирает бинарник и запускает его во временном рабочем каталоге. Проверяет страницы, профили, отказ от неверных данных, Host/Origin и сохранение после перезапуска. Реальные evdev/uinput требуют оборудования; в среде разработки `/dev/input` недоступен.
